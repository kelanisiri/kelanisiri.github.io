# Kelanisiri Aluminium & Steel Contracts

Premium portfolio website for **Kelanisiri Aluminium & Steel Contracts** (Gonawala, Kelaniya, Sri Lanka).

## Live site

https://kelanisiri123-web.github.io/kelanisiri123-web/

## Local development

```bash
npm install
npm run process-images
npm run dev
```

## Add project photos

Drop images into:

```text
images/pantry-cupboards/
images/gates/
images/roofs/
images/others/
```

Then run `npm run process-images` (also runs automatically before `dev` / `build`).

## Deploy

Pushes to `main` build and publish via GitHub Pages (Actions).
