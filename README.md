# Kelanisiri Aluminium & Steel Contracts

Premium portfolio website for **Kelanisiri Aluminium & Steel Contracts** (Gonawala, Kelaniya, Sri Lanka).

## Live site

https://kelanisiri123-web.github.io/

> To use `https://kelanisiri.github.io/` instead, rename the GitHub username (or create an organization) to **kelanisiri**, then create/move this site into a `kelanisiri.github.io` repository.

## Local development

```bash
npm install
npm run process-images
npm run dev
```

## Add project photos

Drop images into:

```text
images/pantry-cupboards/
images/gates/
images/roofs/
images/others/
```

Then run `npm run process-images` (also runs automatically before `dev` / `build`).

## Deploy

Pushes to `main` publish via GitHub Pages Actions.
