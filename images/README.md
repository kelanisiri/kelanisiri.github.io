# Source project photographs

Drop original photos into a category folder. Do not edit files here after adding them —
run `npm run process-images` to generate web-optimized versions.

```
images/
  pantry-cupboards/   ← JPG/PNG photos
  gates/
  roofs/
  others/
  any-new-category/   ← auto-detected on next process run
```

Originals are never modified. Optimized output goes to `public/images/work/`.
